## 📌 Overview

The **Simple Interest Calculator** is an intuitive financial tool designed for students, investors, and educators. It enables users to quickly calculate the interest earned or owed on an investment or loan, assess total repayment amounts, visualize the principal-to-interest distribution ratio, and view annual growth breakdown schedules.

---

## 📐 The Simple Interest Formula

Simple Interest ($SI$) is computed using the standard mathematical formula:

$$\text{Simple Interest (SI)} = \frac{\text{Principal (P)} \times \text{Rate of Interest (R)} \times \text{Time (T)}}{100}$$

$$\text{Total Maturity Amount} = \text{Principal (P)} + \text{Simple Interest (SI)}$$

### Terminology:
- **Principal ($P$):** The initial amount of money invested or borrowed.
- **Annual Rate of Interest ($R$):** The percentage charged or earned per annum (% per year).
- **Time ($T$):** The duration for which the principal amount is invested or borrowed (in years).

## 🧮 Input Details & Calculation Example

### Example Scenario:
- **Principal ($P$):** \$10,000
- **Annual Interest Rate ($R$):** 6.5% per annum
- **Time Period ($T$):** 3 Years

### Step-by-Step Calculation:
1. **Compute Simple Interest:**
   $$\text{SI} = \frac{10000 \times 6.5 \times 3}{100}$$
   $$\text{SI} = \frac{195000}{100} = \$1,950.00$$

2. **Compute Total Maturity Amount:**
   $$\text{Total Amount} = P + \text{SI} = \$10,000 + \$1,950 = \$11,950.00$$

## ✨ Features

- ⚡ **Instant & Real-Time Calculation:** Automatically updates calculations as inputs or sliders change.
- 🎚️ **Interactive Sliders & Quick Chips:** Easily adjust values using numeric inputs, range sliders, or one-click preset buttons (+1k, +5k, 5%, 8%, etc.).
- 🔄 **Years & Months Toggle:** Seamlessly switch between yearly and monthly duration modes.
- 💱 **Multi-Currency Support:** Choose between USD (\$), INR (₹), EUR (€), GBP (£), and JPY (¥).
- 📊 **Visual Distribution Bar:** Interactive visual representation showing the percentage split of Principal vs. Interest Earned.
- 📅 **Annual Growth Breakdown Schedule:** Expandable table showing year-by-year opening balance, interest earned, and closing balance.
- 📋 **One-Click Summary Copy:** Quickly copy formatted calculation results to your clipboard.
- 🌓 **Dark & Light Mode Support:** Sleek modern glassmorphism design with responsive theme switching.
- 📱 **Fully Responsive:** Optimized for desktop monitors, tablets, and mobile devices.

## 🚀 How to Run Locally

This project is built using vanilla HTML, CSS, and JavaScript, meaning **no server or build tools are required**.

1. **Clone the repository:**
   ```bash
   git clone https://github.com/DJ1306/simple-interest-calculator.git
   ```

2. **Navigate to the project folder:**
   ```bash
   cd simple-interest-calculator
   ```

3. **Open the project:**
   - Simply double-click `index.html` in your file explorer to open it in any web browser (Chrome, Edge, Firefox, Safari).
   - Alternatively, open with VS Code Live Server or run a local server:
     ```bash
     npx serve .
     ```

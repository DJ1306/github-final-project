## 📌 Project Description

The **Simple Interest Calculator** is an intuitive, web-based financial tool designed for students, investors, educators, and borrowers. It enables users to quickly calculate the interest earned or owed on an investment or loan, assess total repayment amounts, visualize the principal-to-interest distribution ratio, and view annual growth breakdown schedules.

---

## 🎯 Purpose of the Calculator

The purpose of this calculator is to provide a fast, accurate, and accessible method for determining simple interest without requiring manual computations. It helps users:
- Plan personal investments, savings deposits, or loans.
- Understand the financial cost of borrowing or returns on lending.
- Compare different interest rates and tenures interactively with real-time feedback.
- Eliminate calculation errors through automated and transparent step-by-step arithmetic.

---

## 📐 Simple Interest Formula

Simple Interest is computed using the standard mathematical formula:

```
Simple Interest = (Principal × Rate × Time) / 100
```

In mathematical notation:

$$\text{Simple Interest (SI)} = \frac{\text{Principal (P)} \times \text{Rate of Interest (R)} \times \text{Time (T)}}{100}$$

$$\text{Total Maturity Amount} = \text{Principal (P)} + \text{Simple Interest (SI)}$$

---

## 🔍 Explanation of Principal, Rate, and Time

- **Principal ($P$):** The initial amount of money deposited, invested, or borrowed before interest begins to accrue.
- **Rate ($R$):** The annual rate of interest charged or earned, expressed as a percentage per annum (% per year).
- **Time ($T$):** The duration or period for which the principal amount is borrowed or invested, measured in years (or converted from months).

---

## 🧮 Calculation Example

### Example Scenario:
- **Principal ($P$):** \$10,000
- **Annual Interest Rate ($R$):** 6.5% per annum
- **Time Period ($T$):** 3 Years

### Step-by-Step Calculation:
1. **Compute Simple Interest:**
   $$\text{Simple Interest} = \frac{10000 \times 6.5 \times 3}{100}$$
   $$\text{Simple Interest} = \frac{195000}{100} = \$1,950.00$$

2. **Compute Total Maturity Amount:**
   $$\text{Total Amount} = \text{Principal} + \text{Simple Interest} = \$10,000 + \$1,950 = \$11,950.00$$

## 📖 How to Use the Calculator

Using the Simple Interest Calculator is simple and straightforward:

1. **Enter the Principal Amount:**
   - Type your starting amount directly in the **Principal Amount** field or drag the interactive slider (e.g., $10,000).
   - Use the convenient preset buttons (**+$1k**, **+$5k**, **+$10k**, **+$25k**) for quick adjustments.

2. **Specify the Annual Interest Rate:**
   - Enter the annual percentage rate in the **Annual Interest Rate (%)** field or adjust the slider (e.g., 6.5%).
   - You can also click the quick rate buttons (**5%**, **7%**, **8.5%**, **10%**, **12%**).

3. **Set the Time Duration:**
   - Choose your preferred tenure mode using the **Years / Months** toggle switch.
   - Enter the duration in the **Time Period** field or use the duration slider.

4. **Review Instant Calculation Results:**
   - **Simple Interest:** The interest earned or payable over the selected duration.
   - **Total Maturity Amount:** The sum of your principal plus the computed interest.
   - **Visual Distribution Bar:** A dynamic progress bar showing the percentage split of Principal vs. Interest.
   - **Annual Growth Schedule:** An expandable breakdown showing year-by-year opening balance, interest earned, and closing balance.

5. **Additional Utilities:**
   - **Currency Selector:** Change between USD ($), INR (₹), EUR (€), GBP (£), and JPY (¥).
   - **Copy Summary:** Copy a formatted calculation report to your clipboard with one click.
   - **Reset:** Click the Reset button to return all inputs to their default values.
   - **Dark / Light Mode:** Toggle between sleek dark glassmorphism and crisp light mode.

## 🚀 How to Run Locally

This project is built using vanilla HTML, CSS, and JavaScript, meaning **no build steps or external dependencies are required**.

1. **Clone the repository:**
   ```bash
   git clone https://github.com/DJ1306/github-final-project.git
   ```

2. **Navigate to the project folder:**
   ```bash
   cd github-final-project
   ```

3. **Open the project:**
   - Simply double-click `index.html` in your file explorer to open it in any web browser (Chrome, Edge, Firefox, Safari).
   - Alternatively, open with VS Code Live Server or run a local server:
     ```bash
     npx serve .
     ```
